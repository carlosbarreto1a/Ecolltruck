# Manual do Operador

Instrucoes para acompanhamento da frota e validacao de dados.

## Acompanhamento no Mapa
1. Acesse a pagina de Monitoramento.
2. O mapa exibira a localizacao atual dos veiculos com rotas ativas.
3. Clique sobre o veiculo desejado para consultar o nome do motorista, velocidade e progresso da rota.

## Validacao de Pesagem
1. Acesse a tela de Registro de Peso.
2. Verifique os valores de pesagem informados na balanca.
3. Se o valor inserido ultrapassar o limite permitido para o caminhão, o sistema exibira um alerta de carga excedida.
