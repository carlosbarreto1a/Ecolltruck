# Manual do Administrador

Instrucoes para gerenciamento de usuarios, veiculos e relatorios.

## Cadastro de Veiculos
1. Acesse o menu Caminhoes.
2. Clique no botao de cadastrar novo veiculo.
3. Preencha a placa, o modelo e a capacidade maxima de carga em quilos.
4. Salve o registro. O veiculo ficara disponivel imediatamente nas telas de rotas e pesagem.

## Cadastro de Usuarios
1. Acesse a pagina de Usuarios.
2. Informe o nome, e-mail, senha inicial e o cargo (Administrador, Operador ou Motorista).
3. Para desativar o acesso de uma pessoa, altere o status da conta na lista de cadastrados.

## Emissao de Relatorios
1. Acesse a tela de Relatorios ou Registro de Pesagem.
2. Selecione o periodo e os filtros desejados.
3. Clique na opcao de exportar para gerar o arquivo em PDF ou Excel.
