# Visao Geral do Sistema EcollTruck

O EcollTruck e um sistema voltado para a gestao de coleta de residuos, controle de pesagem e monitoramento de frota. O objetivo da plataforma e integrar a operacao de campo com o acompanhamento em tempo real feito pela central.

## Objetivos
- Acompanhar o deslocamento dos veiculos em operacao de forma continua.
- Registrar os dados de pesagem e identificar divergencias de capacidade nos veiculos.
- Garantir a restricao de funcionalidades conforme o perfil de cada usuario.
- Permitir a exportacao de dados operacionais em formatos padrão como PDF.

## Estrutura da Documentacao
A documentacao do projeto esta dividida nas seguintes partes:
- visao-geral.md: Apresentacao basica da plataforma.
- perfis-de-acesso.md: Regras de navegacao, permissoes e bloqueios.
- manuais/administracao.md: Instrucoes para cadastro de frota e usuarios.
- manuais/operacao.md: Instrucoes para acompanhamento no mapa e balanca.
- manuais/motorista.md: Instrucoes para utilizacao do GPS e rotas no celular.
